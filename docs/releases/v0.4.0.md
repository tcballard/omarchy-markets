# More room for your markets

Markets 0.4.0 gives the watchlist more room and the selected chart a clearer
hierarchy. Company names sit beneath symbols, prices and daily changes line up,
and chart ranges live beside the chart they control.

- A wider panel, larger selected price and taller chart.
- Collapse the chart and statistics for a compact watchlist; restore with
  Show chart or D. The choice is remembered until the plugin reloads.
- Explicit comparisons: daily change versus previous close, chart return from
  the first plotted price, with a matching dashed baseline.
- Honest loading and unavailable states when switching history ranges.
- A provider footer kept inside the panel, with scrolling above it.
- Existing watchlists, pinned symbols and ticker settings preserved.

```bash
omarchy plugin update io.github.tcballard.omarchy-markets
```
