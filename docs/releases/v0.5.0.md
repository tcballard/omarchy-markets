# Your watchlists, with a closer look at every chart

Markets v0.5.0 lets you keep separate watchlists and inspect the history behind
the price. Switch from your daily list to crypto or a research list without
rebuilding it each time.

**Release preparation: not yet published.** Live XPS acceptance and a current
preview are still pending. The existing screenshots show earlier releases.

## What changes

- **Keep up to eight watchlists.** Start empty or copy your current list,
  rename it, and switch between lists with their own symbols, order and pinned
  quote. Each list holds up to twelve symbols. Deleting a list asks first.
- **See what is moving.** Sort the panel by daily percentage gainers or losers.
  Your saved order and ticker stay intact, and refreshing prices keeps the same
  instrument selected.
- **Read a point on the chart.** Hover or click to see its sampled price and UTC
  timestamp. Press **I** for keyboard inspection, use **Left/Right** or
  **Home/End**, then **Escape** to return to the panel controls. Inspection uses
  the history already loaded; moving between points makes no extra request.
- **Pick up where you left off.** Your active list and sort preference survive
  a shell restart.
- **Keep the popup compact without scrolling.** The watchlist and selected chart
  have separate views, longer lists use two columns, and management controls
  have their own sections. Open Chart for detail and Watchlist to return.
- **Know how old the price is.** Fetch time and quote time have separate labels,
  including when chart details are hidden. Quotes older than expected for their
  market session are marked stale; ordinary closing prices remain useful while
  the market is closed. Regular-session prices are labelled explicitly.
- **Read the right units.** Index levels and changes use points. Tiny crypto
  prices retain significant digits instead of rounding a nonzero price to zero.
- **A tidier watchlist editor.** The Add button now aligns with its symbol
  field. Thanks to **Shawn Yeager (@shawnyeager)** for the original contribution
  in [#11](https://github.com/tcballard/omarchy-markets/pull/11).

## Existing settings

Your current watchlist becomes the starting list. Symbols, order, pinned quote,
data consent and ticker settings carry over; creating or switching lists does
not grant permission to fetch data. The plugin ID and installation path stay
the same. Back up the widget settings before testing; v0.4.0 cannot manage the
new named-list library. See the [test and rollback guide](v0.5.0-testing.md).

## Compatibility and evidence

The target remains **Omarchy Quattro on Linux x86_64**, with system Python
3.10+. No new runtime dependency or account is required.

The merged feature work passed portable regression tests and offscreen Qt
checks, including **Qt 6.12.0**. The release-preparation PR reruns those checks
against its candidate and packages that exact source after they pass. These
tests use host stubs; live Omarchy input, lifecycle, themes and display checks
remain separate acceptance work. ARM64 support is not claimed.

After publication, existing users can update with:

```bash
omarchy plugin update io.github.tcballard.omarchy-markets --yes &&
omarchy restart shell
```

This command follows upstream main; it does not install the preparation branch
or pin a release. New users can follow the [README](../../README.md#install).

Quotes use Yahoo Finance's unofficial endpoint and may be delayed or unavailable.
Markets provides an informational view, with no trading or portfolio tools.
Marketplace snapshot verification remains separate from release publication.
