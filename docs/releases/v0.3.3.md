# Market data, without the permanent loading screen

Some third-party installations could sit on **Loading** because Markets relied
on shell internals that the public plugin API does not expose. This release
uses the public service lookup and resolves its bundled helper directly from
its own QML location. Installation paths containing spaces and URL-encoded
characters are covered by portable regression checks.

- Handles public registry notifications without startup signal warnings.
- Includes real Omarchy screenshots with their capture provenance.
- Adds clearer install/update instructions and marketplace, release, CI and
  licence badges.
- Clarifies normal-user permissions, removing the README wording that produced
  a false positive in the marketplace's privilege scan.

Update with:

```bash
omarchy plugin update io.github.tcballard.omarchy-markets
```

This is the repository's first tagged GitHub release. The manifest, annotated
`v0.3.3` tag, source archive, source manifest, SPDX package inventory and checksums
refer to the same commit. Installation through Omarchy follows current `main`.

Validation: 65 Python tests, 50 model tests, 24 lifecycle tests, public-plugin-API
regressions, manifest validation and deterministic fixtures. Release automation
reruns those checks and verifies downloaded draft assets before publishing.

The included screenshots show 0.3.2 on Omarchy revision
`4ee6d4eeea176b0bf4014ce8b82a148a9433efff`, captured on 12 September 2026.
This release has not had a fresh live Omarchy install/update/removal or
multi-monitor acceptance pass. Existing visual limitations and remaining host
checks are recorded in [the acceptance matrix](https://github.com/tcballard/omarchy-markets/blob/v0.3.3/docs/acceptance.md).

Marketplace verification is a separate exact-commit decision, tracked in
[request #6586](https://github.com/omacom/omarchy-plugin-marketplace/issues/6586).
Publishing this release does not itself verify the new marketplace snapshot.
