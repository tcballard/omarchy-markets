# A clearer market view, with less baggage

Markets now keeps the panel inside its border, with scrolling when your
watchlist or display needs it. Secondary text follows the popup's colours and
falls back to the main text colour when the muted shade is hard to read.

Underneath, the quote helper starts with isolated Python settings, unsafe
cache files are ignored, and old chart files are cleared within a shared disk
budget. Existing watchlists, pins, ticker settings and cached quotes carry over.

- Scroll through setup and full watchlists with the mouse; keyboard selections
  stay visible too.
- Keep history caching within 60 files and 8 MiB, with expired entries and
  abandoned writes cleaned up before another history result is saved.
- Find the install command and product overview in a shorter README, with
  detailed configuration moved into the reference guide.

Update after publication:

```bash
omarchy plugin update io.github.tcballard.omarchy-markets
```

Release preparation: portable checks cover helper isolation, cache safety and
budgets, v0.3.3 settings/cache compatibility, contrast and scrolling logic.
The release workflow requires an exact-commit host record before publishing
and includes that record with the source archive and checksums. Refer to
`HOST-ACCEPTANCE.json` in the published assets for the observed host results
and remaining limitations.

The existing screenshots show v0.3.2. Fresh captures and marketplace snapshot
verification are separate from this release preparation.
